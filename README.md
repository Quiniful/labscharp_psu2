# Козарчук Никита ИТ-2 Лабораторная №2

В отчёте описан текущий код проекта. Все значения вводятся с клавиатуры.
Для сотрудников есть отдельные команды назначения отдела и вывода списка.

# Задание 1

## Задача 4

### Текст задачи

Создать сущность «Время», описываемую количеством секунд с начала суток.
Выводить время в формате «ЧЧ:ММ:СС». Если прошло больше суток, показывать
время последних суток. Проверить 10, 10000 и 100000 секунд.

### Алгоритм решения

Пользователь вводит три значения секунд. Для каждого объекта в `ToString()`
берётся остаток от деления на 86400, затем вычисляются часы, минуты и секунды.

## Задача 5

### Текст задачи

Создать сущность «Дом», описываемую количеством этажей. Получить текстовую
форму «дом с N этажами» с правильным окончанием. Пользователь вводит
количество домов и количество этажей для каждого дома.

### Алгоритм решения

Сначала вводится количество домов. В цикле для каждого дома вводится число
этажей и создаётся объект `House`. Свойство `Floors` хранит это значение,
а `ToString()` выбирает окончание слова.

# Задание 2

## Задача 4

### Текст задачи

Создать сущности «Сотрудник» и «Отдел». У отдела есть название и начальник.
Сотрудник выводится с названием отдела и именем начальника. Пользователь
вводит количество сотрудников, их имена, название отдела и имя начальника.

### Алгоритм решения

# Задание 4

## Задача 3

### Текст задачи

Изменить сущность «Дом». Дом создаётся с количеством этажей, которое нельзя
изменить после создания. Пользователь вводит количество домов и этажи домов
с 2, 35 и 91 этажом. Затем программа сообщает, что у `Floors` нет сеттера.

### Алгоритм решения

Количество этажей хранится в закрытом поле. Свойство `Floors` содержит только
`get`, поэтому изменить значение после создания объекта нельзя.

# Задание 5

## Задача 1

### Текст задачи

Создать сущность «Пистолет» с количеством патронов. При наличии патронов
метод выводит «Бах!» и уменьшает количество на один. При пустом магазине
выводится «Клац!». Пользователь выбирает конструктор, вводит патроны и число
выстрелов.

Пользователь выбирает пистолет по умолчанию или вводит начальное количество
патронов. Затем вводится число выстрелов. Цикл вызывает `Shoot()` указанное
число раз.
