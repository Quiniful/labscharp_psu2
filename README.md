# Задание 1

## Задача 4

### Текст задачи

Создать сущность «Время». Она описывается количеством секунд,
прошедших с начала суток. Время нужно выводить в формате «ЧЧ:ММ:СС».
Если количество секунд больше суток, показывается время последних суток.
Вывести время для 10, 10000 и 100000 секунд.

### Алгоритм решения

В конструкторе оставляю остаток от деления секунд на количество секунд
в сутках. Часы получаю целочисленным делением на 3600. Минуты получаю
из оставшихся минут, секунды — из остатка от деления на 60.

# Задание 4

## Задача 3

### Текст задачи

Изменить сущность «Дом». Дом создаётся только с указанием количества
этажей. После создания количество этажей изменить нельзя. Создать дома
с 2, 35 и 91 этажом и показать, что свойство `Floors` доступно только
для чтения.

### Алгоритм решения

Количество этажей хранится в закрытом поле `readonly`. В конструкторе
значение задаётся один раз. Публичное свойство содержит только `get`,
поэтому после создания объекта присвоить новое количество этажей нельзя.

# Задание 5

## Задача 1

### Текст задачи

Создать сущность «Пистолет» с количеством патронов. Пистолет можно
создать с начальным количеством патронов или без параметров. В последнем
случае он заряжен пятью патронами. При выстреле вывести «Бах!», если
патроны есть, и уменьшить их количество. Если патронов нет, вывести
«Клац!». Создать пистолет с тремя патронами и выстрелить пять раз.

### Алгоритм решения

В классе хранится количество патронов. Метод `Shoot()` проверяет это
количество. При положительном значении выводится «Бах!» и число патронов
уменьшается на один. При нуле выводится «Клац!», а значение не меняется.
