# Козарчук Никита ИТ-2 Лабораторная №2

В отчёте описан текущий код проекта. Все значения вводятся с клавиатуры.
Для времени сначала вводится количество значений. Для сотрудников есть
отдельные команды назначения сотрудника, назначения начальника и вывода.

# Задание 1

## Задача 4

### Текст задачи

Создать сущность «Время», описываемую количеством секунд с начала суток.
Выводить время в формате «ЧЧ:ММ:СС». Если прошло больше суток, показывать
время последних суток. Проверить 10, 10000 и 100000 секунд.

### Алгоритм решения

Пользователь сначала вводит количество значений времени. Затем для каждого
объекта вводится число секунд. В `ToString()` берётся остаток от деления
на 86400, затем вычисляются часы, минуты и секунды.

# Задание 2

## Задача 4

### Текст задачи

Создать сущности «Сотрудник» и «Отдел». У отдела есть название и
начальник, который также является сотрудником. Сотрудник выводится с
названием отдела и именем начальника. Пользователь вводит сотрудников и
может распределить их по нескольким отделам. Начальник назначается отдельно
из сотрудников своего отдела.

### Алгоритм решения

Сначала вводится список сотрудников. Команда `1` позволяет выбрать или
создать отдел и назначить в него одного сотрудника. Команда `2` отдельно
назначает начальника из сотрудников выбранного отдела. Команда `3` выводит
сотрудников выбранного отдела. Команда `0` завершает работу с отделами.

## Задача 3

### Текст задачи

Изменить сущность «Дом». Дом создаётся с количеством этажей, которое нельзя
изменить после создания. Пользователь вводит количество домов и этажи домов

# Задание 5

## Задача 1

### Текст задачи

Создать сущность «Пистолет» с количеством патронов. При наличии патронов
метод выводит «Бах!» и уменьшает количество на один. При пустом магазине

патронов. Затем вводится число выстрелов. Цикл вызывает `Shoot()` указанное
