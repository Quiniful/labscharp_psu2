## Задача 4

### Текст задачи

Время. Создайте сущность Время , которое будет описывать текущее время суток в
24 -х часовом формате. Время описывается числом секунд, прошедшим с начала
суток. Время может быть приведено к текстовой форме следующего формата:
“ЧЧ:ММ:СС”. Например,если время задано как 12000, то текстовая форма будет
“3:20:00”. Если общее время превышает 24 часа, то отображаться в текстовом виде
должно только то время, которое прошло с начала последних суток, например 91800,
это не 25:30:00, а 1:30:00. Необходимо создать и вывести на экран текстовую
форму для следующих вариантов времени:

- 10 секунд

- 10000 секунд

- 100000 секунд

### Алгоритм решения

1. Создать класс Time с целочисленным полем seconds для хранения количества
   секунд с начала суток.
2. Добавить конструктор, принимающий количество секунд, и свойство Seconds с get
   для чтения этого значения.
3. Реализовать ToString(): найти остаток от деления секунд на 86400, затем
   вычислить часы, минуты и секунды. Если остаток отрицательный, прибавить
   86400.
4. Составить строку «ЧЧ:ММ:СС», записывая каждую часть времени двумя цифрами.
5. В Main через метод Run запросить количество значений времени и число секунд
   для каждого объекта, затем вывести объекты через Console.WriteLine. Для
   примеров из условия ввести 10, 10000 и 100000.

### Поля класса

| Поле | Тип | Назначение |
| --- | --- | --- |
| `Time.seconds` | `int` | Количество секунд, переданное при создании объекта. |

### Конструкторы, свойства и методы

- Конструктор `Time(int seconds)` сохраняет количество секунд.
- Свойство `Seconds` возвращает исходное значение поля; `set` отсутствует.
- Метод `ToString()` переводит секунды в время последних суток и возвращает
  строку в формате «ЧЧ:ММ:СС».

## Задача 5

### Текст задачи

Дом. Создайте сущность Дом, которая описывается количеством этажей в виде числа.
У Дома можно запросить текстовую форму, которое имеет представление вида “дом с
N этажами”, где N это число. Гарантировать правильное окончание фразы, в
зависимости от количества этажей. Создать и вывести на экран дома с 1, 5, 23
этажами.

### Алгоритм решения

1. Создать класс House с целочисленным полем floors для количества этажей.
2. Добавить конструктор, принимающий количество этажей, и свойство Floors для
   чтения значения поля.
3. Реализовать ToString(): выбрать «этажом», если последняя цифра равна 1 и
   последние две цифры не равны 11; иначе выбрать «этажами».
4. Вернуть строку «дом с N этажом» или «дом с N этажами».
5. В Main через ShowHouses запросить количество домов и этажность каждого.
   Создать объекты и вывести их через Console.WriteLine. Для примеров из условия
   ввести 1, 5 и 23 этажа.

### Поля класса

| Поле | Тип | Назначение |
| --- | --- | --- |
| `House.floors` | `int` | Количество этажей дома. |

### Конструкторы, свойства и методы

- Конструктор `House(int floors)` задаёт количество этажей.
- Свойство `Floors` возвращает количество этажей и содержит только `get`.
- Метод `ToString()` формирует описание дома с правильным окончанием: «этажом»

# Задание 2

## Задача 4

### Текст задачи

Сотрудники и отделы. Создайте сущность Сотрудник, которая описывается именем (в
строковой форме) и отделом, в котором сотрудник работает, причем у каждого
отдела есть название и начальник, который также является Сотрудником. Сотрудник
может быть приведен к текстовой форме вида: “Имя работает в отделе Название,
начальник которого Имя ”. В случае если сотрудник является руководителем отдела,
то текстовая форма должна быть “Имя начальник отдела Название”. Необходимо
выполнить следующие задачи:

1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
2. Сделать Козлова начальником IT отдела.
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих
   должен оказаться один и тот же отдел и начальник).

### Алгоритм решения

1. Создать класс Employee с полями name для имени и department для ссылки на
   отдел.
2. Создать класс Department с полями name для названия, boss для начальника и
   employees для списка сотрудников.
3. Добавить конструкторы и свойства Name и Department у сотрудника, а также
   Name, Boss и Employees у отдела. Для каждого свойства написать get или set с
   обращением к полю.
4. При назначении сотрудника в отдел добавлять его в список этого отдела. При
   переводе удалять из прежнего списка; если он был начальником, освобождать
   должность.
5. Реализовать ToString() сотрудника: для начальника вернуть «Имя начальник
   отдела Название», для остальных — имя, отдел и имя начальника. Отдельно
   обработать отсутствие отдела или начальника.
6. В Main через ReadEmployees запросить количество сотрудников и их имена. Через
   WorkWithDepartment отдельно назначить сотрудников в отделы, выбрать
   начальника и вывести сотрудников. Для примера из условия создать Петрова,
   Козлова и Сидорова, назначить им отдел IT и сделать Козлова начальником.

### Поля класса

| Поле | Тип | Назначение |
| --- | --- | --- |
| `Employee.name` | `string` | Имя сотрудника. |
| `Employee.department` | `Department` | Отдел, в котором работает сотрудник; null, если отдел не назначен. |
| `Department.name` | `string` | Название отдела. |
| `Department.boss` | `Employee` | Начальник отдела; null, если начальник не назначен. |
| `Department.employees` | `List<Employee>` | Список сотрудников данного отдела. |

### Конструкторы, свойства и методы

- Конструктор `Employee(string name)` сохраняет имя; отдел первоначально не
  назначен.
- Свойство `Employee.Name` возвращает имя. Свойство `Employee.Department`
  позволяет читать и назначать отдел, обновляя списки сотрудников при переводе.
- Конструктор `Department(string name, Employee boss)` задаёт название,
  начальника и создаёт пустой список сотрудников.
- Свойства `Department.Name` и `Department.Employees` предоставляют доступ для
  чтения. Свойство `Department.Boss` содержит `get` и `set` для отдельного
  назначения начальника.
- Методы `AddEmployee()` и `RemoveEmployee()` добавляют и удаляют сотрудника.
  Удаление начальника освобождает его должность.
- Метод `Employee.ToString()` возвращает сведения о сотруднике, отделе и
  начальнике. Метод `Department.ToString()` возвращает название отдела.

## Задача 1

### Текст задачи

Пистолет стреляет.

- Создайте сущность Пистолет, которая описывается следующим образом:

- Имеет Количество патронов (целое число)

- Может быть создан с указанием начального количества патронов

- Может быть создан без указания начального количества патронов, в этом случае
  он изначально заряжен пятью патронами.

- Может Стрелять, что приводит к выводу на экран текста “Бах!” в том случае,
  если количество патронов больше нуля, иначе делает “Клац!”. После каждого
  выстрела (когда вывелся “Бах!”) количество патронов уменьшается на один.
  Создайте пистолет с тремя патронами и выстрелите из него пять раз.

### Алгоритм решения

1. Создать класс Gun с целочисленным полем bullets для количества патронов.
2. Добавить два конструктора: Gun(int bullets) с заданным количеством патронов и
   Gun() с пятью патронами.
3. Добавить свойство Bullets с get и метод ToString() для получения сведений о
   количестве патронов.
4. Реализовать Shoot(): если патроны есть, вывести «Бах!» и уменьшить bullets на
   один; иначе вывести «Клац!», не меняя количество патронов.
5. В Main запросить способ создания пистолета, начальное количество патронов при
   необходимости и число выстрелов. Создать объект и вызвать Shoot() в цикле.
   Для примера из условия ввести три патрона и пять выстрелов: получить три
   «Бах!» и два «Клац!».

### Поля класса

| Поле | Тип | Назначение |
| --- | --- | --- |
| `Gun.bullets` | `int` | Текущее количество патронов в пистолете. |

### Конструкторы, свойства и методы

- Конструктор `Gun(int bullets)` задаёт начальное количество патронов.
- Конструктор `Gun()` создаёт пистолет с пятью патронами.

# Работа с программой

Во всех заданиях данные вводятся с клавиатуры. Сначала вводится количество
значений времени, затем секунды для каждого значения. В заданиях с домами
вводятся число домов и этажность каждого.

Для сотрудников сначала вводятся их количество и имена. Команды: `1` — назначить
одного сотрудника в выбранный или новый отдел; `2` — отдельно назначить
начальника из сотрудников отдела; `3` — вывести сотрудников выбранного отдела;
`0` — продолжить. Поддерживаются несколько отделов и перевод сотрудника между
ними.

В задании 3.4 вводится имя сотрудника, и список получается через ссылку на него.
Для пистолета выбирается способ создания, затем вводится число выстрелов.
